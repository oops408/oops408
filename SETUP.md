# Setup

1. Create a public GitHub repository named exactly `oops408` under the `oops408` account.
2. Copy all files from this package into that repository.
3. Keep the default branch named `main`.
4. Open the Actions tab and enable workflows.
5. Run **Generate contribution snake** once manually. It will publish the snake SVG to the `output` branch.
6. Replace the contact placeholder in `README.md` with your LinkedIn, portfolio, email, LeetCode, Spotify, and WakaTime URLs when available.
7. Commit and push.

GitHub limits custom CSS and JavaScript in README files, so the design uses GitHub-safe Markdown, HTML, externally rendered cards, and SVG assets.
